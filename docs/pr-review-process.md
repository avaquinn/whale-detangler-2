# Review Checklist
When a pull request is submitted, a review process is first performed on the pull request.

## Overall Pull Request Review
- Perform a [correctness review](correctness-review.md)
- Perform a [security review](security-review.md)
- All automated tests pass
- All requested changes have been addressed and merged
- No unresolvable merge conflicts
- No additional unaddressed issues
- No commits within the PR are unaccounted for

## Performing the Correctness and Security Reviews
- Both tests should be done by a seperate reviewer that is not the author

Once all of the above has been fully approved, then the PR can be merged.
