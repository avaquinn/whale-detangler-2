# Security Policy

## Supported Versions
- Security updates are provided for the latest stable version only
| Version | Supported |
|---------|-----------|
|Current development version|Yes|
|Old versions|No|

## Vulnerability Reporting
- If you discover a vulnerability, please report it privately to the project maintainers.
- Make sure to include:
  - A detailed description of the vulnerability
  - Steps to reproduce the issue
  - Potential impact
  - Suggested fix
- Please do not include any sensitive information in the report.

## Response
- Maintainers will access submitted reports and determine the appropriate response from there.
- Any confirmed vulnerability will be patched in the next release after a review process and testing.

## DevSec Policy
The project employs the following security policy for development:
- Code changes require a pull request at all times.
- Pull requests must go through an extensive review process documented [here](pr-review-process.md).
- Automated scanning technologies, like secret scanning, dependency scanning, and static analysis, are used
- All dependencies and build instructions are documented.
